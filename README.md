# nillebco Homebrew tap

Homebrew formulae for [nillebco](https://github.com/nillebco) tools.

```sh
brew tap nillebco/tap
brew install <formula>
```

## Formulae

| Formula | Description |
|---|---|
| [`varda`](https://github.com/nillebco/varda) | Routes markdown tasks to AI agents (Claude, Codex, Copilot) and tracks their lifecycle |

## Updating

```sh
brew update && brew upgrade varda
```

Formulae are generated and pushed automatically by each project's release
workflow ([cargo-dist](https://opensource.axo.dev/cargo-dist/)) — don't edit them by hand.
